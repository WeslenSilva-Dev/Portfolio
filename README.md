# Portfolio - Backend Developer

Site de portfolio em tema de terminal, com layout em uma única página e estilização inspirada em interface de linha de comando.

---

## Como Executar

Abra o arquivo `index.html` diretamente no navegador. Não é necessário servidor nem instalação de dependências. As fontes são carregadas via Google Fonts (JetBrains Mono e Fira Code).

---

## Tecnologias

- HTML5
- CSS3 (variáveis customizadas, Flexbox, Grid, animações)
- JavaScript (vanilla), usado para observador de scroll e easter egg
